# 음원 넣는 곳

여기에 mp3(또는 m4a) 파일을 넣고, 같은 폴더의 `manifest.json` 에 적어주면
아빠 화면 → "public/songs 다시 읽기" 버튼으로 앱에 들어온다.

```json
[
  {
    "file": "pororo-firetruck.mp3",
    "title": "뽀로로 소방차 노래",
    "tags": ["뽀로로", "소방차", "자동차"],
    "emoji": "🚒",
    "durationSec": 132
  }
]
```

- `tags` 가 카드 조합과 맞춰지는 부분이다. 카드에 적힌 말을 그대로 넣어주면 된다.
  (예: 뽀로로 카드 + 소방차 카드 → `["뽀로로", "소방차"]`)
- 음원 파일 자체는 저작권이 있으니 git 에 올리지 않는다 (`.gitignore` 에 걸려 있다).
- 합법적으로 받는 방법: 멜론/벅스 등에서 **다운로드 구매**, 또는 가지고 있는 CD 리핑.
